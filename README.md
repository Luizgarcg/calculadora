🧮 Web Calculator

A responsive and functional web calculator built using HTML5, CSS3, and Vanilla JavaScript. The goal of this project was to practice and consolidate fundamental web development concepts and DOM manipulation.

🚀 Features

Basic Operations: Addition, subtraction, multiplication, and division.

Clear Screen: Button to clear the current input (C / AC).

Responsive Design: Adaptable layout for desktop and mobile screens.

Interactivity: Visual button feedback and dynamic display updates.

🛠️ Technologies Used

HTML5: Semantic UI structure and elements.

CSS3: Styling, Grid/Flexbox layout, and responsive design.

JavaScript (ES6+): Program logic, event handling, and mathematical operations.

📂 Project Structure

├── index.html      # Main interface structure
├── style.css       # Visual styling and responsiveness
└── script.js       # Logic and DOM manipulation
